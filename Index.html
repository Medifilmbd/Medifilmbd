মাত্র ২ মিনিটে ফ্রি Firebase সেটআপ গাইড:

  1. গুগল অ্যাকাউন্ট দিয়ে console.firebase.google.com এ যান এবং Create a project ক্লিক করুন।
  2. বাম পাশের মেনু থেকে Build → Realtime Database সিলেক্ট করে Create Database দিন এবং Test Mode চালু করুন।
  3. প্রজেক্ট ওভারভিউ থেকে Web (</>) আইকনে ক্লিক করে অ্যাপ রেজিস্টার করলে যে firebaseConfig কোডটি পাবেন, তা কপি করে বাম পাশের বক্সে পেস্ট করুন।
  4. "ক্লাউডে কানেক্ট ও সিঙ্ক করুন" বাটনে ক্লিক করলেই আপনার Netlify ওয়েবসাইটটি ১০০% লাইভ ক্লাউড ডাটাবেজের সাথে যুক্ত হয়ে যাবে!
